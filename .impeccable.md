## Design Context

This is the Leadoff web app (app.getleadoff.com, also lineupcard.app): the coach and parent companion to the Leadoff iOS app, sharing one live database and one design system. The system is locked. `~/Developer/Leadoff/Brand/DESIGN_RULES.md` (every rule with its reason) and the specs it names win over anything a design skill suggests. Never add a color, font, radius, shadow or curve that isn't already a token in `:root` of `app.html`; if one seems missing, ask Dan.

### Users
Youth baseball and softball team parents and coaches (the primary user is a parent), often on a phone at the field, building or adjusting a lineup in a few minutes before a game. Mobile matters as much as desktop.

### Brand Personality
Stadium announcer meets team mom: confident, warm, a little theatrical, never sarcastic or edgy. Three words: thrilling, simple, heart. Short declarative copy that translates cleanly to Spanish. Kid safety is said out loud.

### Aesthetic Direction
The Crate theme. Cream page #FAF6EB with white quiet cards (no border on cream), near-black ink #101613, grass green #46CF51 as the one interactive color (a fill in light mode; text on it is dark grass #0B2410), pennant red #EC2146 only for one kicker per screen and alerts, amber only for "needs attention". Sticker buttons: 12px radius, 2px ink border, hard 4px offset shadow, no blur. Display face Sofia Sans Extra Condensed 900 caps; body Barlow Semi Condensed. Light and dark mode; dark separates by fill. Anti-references: gradients, glassy blurs, generic SaaS blue, neon, decorative color.

### Design Principles
1. One signature color, one emphasis card and one pennant per screen. When everything is loud, the buttons get lost.
2. One spec per thing: reuse the existing classes (`.btn-primary` / `.btn-outline` / `.btn-ghost`, `.card`, `.lc-toggle`, `.lc-seg`, the field rule) instead of styling a one-off.
3. Values come from the tokens: `--radius-*`, `--type-*`, `--ease-*`, `rgba(var(--shadow-rgb), a)`, spacing steps 2, 4, 6, 8, 12, 16, 20, 24, 32.
4. Motion explains, then gets out of the way: three springs (Snappy, Quick, Pop, plus Glide for resizes), press instant and release springy, a reduced-motion path for everything.
5. Bolder, more colorful or more animated is never a goal by itself. The system is quiet on purpose so the actions stand out; WCAG AA contrast (receipts in BRAND_GUIDELINES §4).
